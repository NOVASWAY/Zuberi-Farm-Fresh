# Image Visibility Guide for Zuberi Fresh Farm Website

## Understanding the Image System

This website uses a hybrid approach to display product images:

1. **Primary Method**: The website first tries to load PNG images from the `public/images/` directory
2. **Fallback Method**: If an image fails to load, the website automatically displays an SVG illustration instead

This ensures that your website will always look good, even if some image files are missing.
