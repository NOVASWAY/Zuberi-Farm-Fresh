# Zuberi Fresh Farm Website

A modern, responsive website for Zuberi Fresh Farm showcasing their products, services, and proprietors.

## Getting Started

Follow these steps to run the website locally:

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone this repository
2. Open a terminal and navigate to the project directory
3. Install dependencies:

```bash
npm install
# or
yarn install
